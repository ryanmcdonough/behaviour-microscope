# Behaviour Microscope — reproducibility package

This repository contains the data, code, notebooks, and recorded outputs for the Authority
Deference in Legal Language Models study. The experiment asks whether attributing a false UK
legal proposition to different sources changes a model's answer, then uses open-weight models
to locate and causally test the effect in the residual stream.

## What is included

```text
data/                 30 sourced England-and-Wales legal scenarios
notebooks/            Colab entry points for every reported model family
src/microscope/       experiment, backends, statistics, quality gates, and plots
scripts/              headless Thomson run and cross-run analysis/build scripts
tests/                CPU-only test suite
results/              17 complete run directories, including plots and manifests
RESULTS.md            generated digest of all included runs
RESEARCH.md           experimental and interpretability design decisions
PAPER_BRIEF.md        findings, caveats, provenance, and writing brief
CLAUDE.md             scientific and implementation constraints for future contributors
```

Each result directory is self-describing. Its `manifest.json` records the model and revision,
package versions, hardware, random seed, generation configuration, phase timings, experiment
arms, and source commit. `quality_report.json` records whether the run passed the study's
pre-specified validity checks.

## Reproduce the published analysis

Python 3.11–3.13 is supported.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
pytest
python scripts/analyse_runs.py
python scripts/build_stack.py --out reproduced-analysis
```

The last command rebuilds the cross-model tables, figures, and results digest entirely from the
versioned contents of `results/`. Compare the generated tables with `RESULTS.md`.

## Re-run model measurements

The notebooks contain the exact experiment configurations used for each model family:

- `run_gemma_plain.ipynb` — Gemma 3 12B, reasoning off, behavioural and mechanistic runs.
- `run_qwen_plain.ipynb` — Qwen3 14B, reasoning off, behavioural and mechanistic runs.
- `run_qwen_thinking.ipynb` — Qwen3 14B, reasoning on, behavioural run.
- `thomson1_colab.ipynb` — Thomson 1.0 Small, reasoning off/on.
- `run_openai_claude.ipynb` — OpenAI and Anthropic behavioural replications.
- `authority_v1_colab.ipynb` — combined/reference workflow.

Before publishing this repository, replace `REPO_URL` in each notebook with the URL of the new
repository. Local open-weight runs need a CUDA GPU; the notebooks state their memory requirements.
Gemma is gated and requires an accepted Hugging Face licence plus `HF_TOKEN`. API runs require
`OPENAI_API_KEY` and/or `ANTHROPIC_API_KEY`. Never commit those values.

For a headless 80 GB GPU machine, Thomson can also be run with:

```bash
python scripts/run_thomson.py --preflight
python scripts/run_thomson.py --plain
python scripts/run_thomson.py
```

For any exact rerun, use the dependency versions in the target run's `manifest.json`; different
included runs used different `interp-engine` versions. Model-provider outputs may vary even with
the recorded deterministic settings, so the API configurations were repeated three times and are
reported as medians with observed ranges.

## Scientific scope

Behavioural change, representational difference, and causal intervention are reported separately.
An activation divergence alone is not treated as a mechanism. Closed-weight API models are
behavioural-only because their activations cannot be captured or patched. Legal ground truth is
stored with primary-source URLs and retrieval dates in `data/authority_v1.jsonl`; it is never
generated by a model.

See `RESEARCH.md` for the complete protocol and `PAPER_BRIEF.md` for the interpretation
limits that apply to the recorded results.
